Excel Formula & Data Analysis Practice
A hands-on Microsoft Excel workbook for practicing spreadsheet formulas, data lookups, salary and billing calculations, and basic sales analysis. The workbook includes sample datasets and worked formula examples that learners can explore, modify, and troubleshoot.
What's included
Workbook: `practice.xlsx`
Worksheet	Practice area
`bill`	Item totals, discounts, conditional `IF` formulas, and final bill amounts
`salary`	Payslip calculations, allowances, provident fund, gross and net salary, and conditional formulas
`COUNT`	Counting values and practicing conditions using sample marks, attendance, age, and gender data
`Sheet1`	Product catalog and `VLOOKUP` examples
`Sheet2`	Employee dataset with salary, department, experience, and performance fields
`Hlookup`	Horizontal employee table for `HLOOKUP` practice
`match`	Product data with `MATCH`, `INDEX`, and combined lookup examples
`Sheet5`	Employee records with `INDEX`/`MATCH` and `XLOOKUP` exercises
`Sheet4`	Customer and order dataset for filtering, aggregation, and analysis
`Sheet10`	Pivot-style summary of unit prices by region and category
`Sheet11`	Pivot-style sales-count summary by salesperson and region
`Sheet6`	Sales orders with lookup examples and fields for regional and product analysis
Skills covered
Counting: `COUNT`, `COUNTA`, `COUNTIF`, `COUNTIFS`
Summation: `SUM`, `SUMIF`, `SUMIFS`
Logical formulas: `IF`, nested `IF`
Lookups: `VLOOKUP`, `HLOOKUP`, `XLOOKUP`, `INDEX`, `MATCH`
Data analysis: Filtering, conditional calculations, and pivot-table-style summaries
> Some functions listed above are suggested practice extensions; not every function is already implemented in the workbook.
Getting started
Download or clone this repository.
Open `practice.xlsx` in Microsoft Excel.
Select a worksheet and inspect its data and existing formulas.
Try writing your own formulas in unused cells or on a copy of the worksheet.
Compare results and experiment with different criteria or lookup values.
Compatibility: Microsoft Excel is recommended. `XLOOKUP` requires a supported Excel version; formulas and pivot features may behave differently in other spreadsheet applications.
Suggested practice challenges
COUNT: Count numeric entries, nonempty cells, and employees meeting a chosen criterion.
SUM: Calculate total sales and sum sales by region or category using `SUMIF`/`SUMIFS`.
VLOOKUP: Retrieve a product's category, price, or supplier using its product ID.
HLOOKUP: Retrieve an employee's department, city, or salary from the horizontal employee table.
INDEX + MATCH: Find a product's price or an employee's details from a matching identifier.
XLOOKUP: Look up an employee name or salary using their employee ID.
IF: Calculate discounts or salary allowances based on conditions.
Pivot analysis: Compare sales across regions, products, and salespeople.
Notes
This is a practice workbook, not a validated financial or payroll model. Some existing formulas, references, and incomplete cells are part of the learning material and may need review or correction. Use a copy when experimenting so the original data remains intact.
